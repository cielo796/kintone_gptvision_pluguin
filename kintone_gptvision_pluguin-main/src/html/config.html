画像解析設定

添付ファイルフィールドの画像をResponses APIで解析し、結果をテキストフィールドに出力します。

推奨
gpt-5.2
最新の標準モデル。画像解析に推奨。

OpenAI設定

組織のセキュリティポリシーに沿って管理してください。
モデルは gpt-5.2 のみ固定です。
モデルにより選択可能な値が異なります。対応しない場合は自動的に調整されます。
未入力時は画像解析用の既定プロンプトを使用します。

kintoneフィールド設定

画像が入っている添付ファイルフィールドコード。
解析結果を保存するテキスト（複数行）フィールドコード。
ボタンを配置するスペースフィールドのID。
